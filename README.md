# YouTube Video Maker Tool

Daily video planning for an English AI and SEO tutorials faceless channel.

## What it does

- **Video Builder** — enter a topic and get a full script with timestamps and on-screen directions.
- **Title Lab** — generate 10 title variations and compare two titles (A/B) with a score to pick the winner.
- **Thumbnail preview** — see 3 thumbnail designs and copy the thumbnail text.
- **SEO Pack** — copy-ready video description and tags for YouTube Studio.
- **Channel A/B plan** — start with 1 channel for 90 days / 20 videos, then compare channels before opening more.
- **Earnings estimator** — estimate earnings from views and RPM.

The default loaded video is "SEO Tutorial for Beginners".

## How to use it

1. Open `index.html` in any browser (double-click the file, or drag it into a browser window).
2. No server, no install, no login needed — it is a single self-contained page.
3. Pick a topic, generate the script, titles, thumbnail and SEO pack, copy them, then record and upload the video in YouTube Studio.

## How to update it

- **Edit directly:** edit `index.html`, commit and push. The live page updates with the commit.
- **Via Muse:** ask Muse to edit the "YouTube Video Maker Tool" artifact, re-export it, then replace `index.html` in this repo with the new export and commit.
